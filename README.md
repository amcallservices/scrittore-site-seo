# Scrittore Site — home SEO multilingue

Sito pubblico separato dall'app Streamlit. Le pagine vengono generate per le lingue `it`, `en`, `es`, `fr`, `de`, `ro`, `ru`, `ar` e `zh`.

## Pubblicazione su Vercel

1. Importa questo repository in Vercel.
2. Lascia rilevare automaticamente il framework Next.js.
3. Pubblica senza configurare variabili d'ambiente.
4. Quando il dominio sarà pronto, collega `scrittore.site` in Vercel e imposta `NEXT_PUBLIC_SITE_URL=https://scrittore.site`.
5. In Google Search Console verifica il dominio e invia `https://scrittore.site/sitemap.xml`.

L'applicazione editoriale resta su `https://scrittoresite.streamlit.app/` ed è collegata dalla home con CTA e iframe demo.
